# ERR0507: a shape whose recursion no pointer bounds has no C name

* class: error — an error, always
* rule: a pointer is what bounds a recursion, and a shape that reaches itself without one has no C name

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
