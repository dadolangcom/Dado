# ERR0534: a method named like a slot of the declaration that holds it

* class: error — an error, always
* rule: a declaration's slots and its methods share one set of names, because `v.name` has to answer exactly one of them

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
