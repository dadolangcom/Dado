# ERR1033: a `threads.spawn` reached by a `#WEB` build that was not built with `--web-threads`

* class: error — an error, always
* rule: the web build is single-threaded unless it is built with `--web-threads`, because a thread on the web is a worker on a shared memory and a module has a shared memory only when it is compiled for one, so a `threads.spawn` a single-threaded `#WEB` build reaches is refused naming the flag

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
