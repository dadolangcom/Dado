# ERR0907: `size` in a `when` condition, which asks the C compiler's number before a line of C exists

* class: error — an error, always
* rule: C owns the layout of the types C invents, so a size is a number the C compiler produces and a `when` folds before any C is written

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
