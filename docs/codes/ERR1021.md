# ERR1021: a value written on a `foreign enum` member, which C supplies, or a backing that is not an integer type

* class: error — an error, always
* rule: a `foreign enum` declares the enumerator names and C supplies every number, so a member's value is not Dado's to write; a backing may be written, and is the integer type a C signature passes the enum as

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
