# ERR0616: a call through a trait value to a method whose signature mentions `Self` beyond its receiver, or that is generic

* class: error — an error, always
* rule: a method is called through a trait value only when its signature mentions `Self` in its receiver alone and binds no type of its own, because the pair does not say which declaration `Self` is

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
