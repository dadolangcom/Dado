# ERR0722: a `#slots` walk over a value with no declared slots to name, or a `break` or `continue` aimed at one

* class: error — an error, always
* rule: `for … in #slots(v)` writes its body out once per slot a declaration names, so it walks a value whose type a declaration wrote with every slot named, and its body has no loop of its own to leave or go round again

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
