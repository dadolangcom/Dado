# ERR1310: a class rule broken — `extends` naming a Dado type or closing a cycle, an override of another shape, `super` outside a subclass or `super(…)` outside `init`, or a class-typed slot with no value

* class: error — an error, always
* rule: a script class extends one script class or `Script`, never a type Dado declares and never itself through its parents; a method it overrides keeps the overridden one's parameters and return; `super` is written only in a class that extends a script class, and `super(…)` only once, as a line of `init`, required when the parent's `init` takes arguments; and a field or local of a class's type is written with its value, since a script has no null

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
