# ERR0823: a `#peek`, `#drain`, discard or `#release` of a channel inside a `for` already walking that channel

* class: error — an error, always
* rule: a channel has one consumer and a walk commits where it ends, so a walk, a discard or a `#release` of a channel is not written inside a walk of the same channel, whose commit would overwrite the inner one's or consume again after the release

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
