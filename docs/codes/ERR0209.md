# ERR0209: a keyword written where a variable, parameter or member name goes

* class: error — an error, always
* rule: a keyword is reserved in every position, so no declaration takes one as its name

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
