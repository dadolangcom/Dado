# ERR0528: a `#channel` written somewhere other than a package-level declaration or a named member of a `type` — a local, a function's signature, an anonymous tuple, a `union` or a `foreign` block

* class: error — an error, always
* rule: a channel is nominal by the declaration holding it, so `#channel` declares one at package level or as a named member of a `type`, and nowhere else

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
