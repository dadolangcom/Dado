# ERR1227: an `#assert_raises` over a function that, or a function it reaches, does not raise into a script

* class: error — an error, always
* rule: `#assert_raises(f, …)` at package level, or `#assert_raises` alone on the line above a function, promises that each function it names raises into a script — that it and every function it reaches, a generic one at each instantiation the program makes, holds nothing foreign and nothing of C's address model: no call of a `foreign` function, no `export`, `@symbol` or local `@c_body`, no `#align_forward`, atomic, `#fence` or `#no_bounds`, and no value whose type is an address (`rawptr`, `cstring`, a `#c.*` scalar, an opaque C type, a C-qualified type) — so a promised function that does not is refused, naming the first node that blocks it, the chain of calls that reached it, and the repair

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
