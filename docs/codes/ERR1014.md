# ERR1014: a foreign slot or type whose C name is not one a C header could have given it

* class: error — an error, always
* rule: a foreign name is written into the emitted C as it stands, so it is one C could have given the thing it names: an identifier for a slot, and for a type an identifier or `struct`, `union` or `enum` and one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
