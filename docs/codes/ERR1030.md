# ERR1030: a `!` on a `@macro` foreign function, or a failable function type in a `foreign` signature

* class: error — an error, always
* rule: C's error conventions are not checkable, so a `foreign` function is failable only as one this compiler wrote — its header marks it, and the emitted C asks the preprocessor for the mark — which a `@macro` never is, and a `foreign` signature never names a failable function type

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
