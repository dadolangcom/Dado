# ERR0524: slot names written inline under a type constructor, which no name receives and no later read can find

* class: error — an error, always
* rule: a view is bound to a name and never to a type, so slot names written inline are written where a name receives them — at the whole of a binding, a parameter or a return, and not under a `^`, a `[]`, a `[N]`, a `ref`, a map half, a layout or another slot

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
