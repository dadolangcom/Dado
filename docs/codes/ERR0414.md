# ERR0414: a name one of the global builtins or the language's own type names already owns

* class: error — an error, always
* rule: a global builtin, or a type name the language itself spells, resolves before any scope, so a declaration of its name could never be reached

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
