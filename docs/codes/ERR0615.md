# ERR0615: a write to a by-value `self`, a slot of it, or its address — a write the caller would never see

* class: error — an error, always
* rule: `self` is a copy made for one call, so a method writes neither it, a slot of it, nor its address; a method that writes its receiver takes `^self`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
