# ERR1031: a `flags` argument that would reach past the package that wrote it — a warning flag no `#pragma GCC diagnostic` spells, or a codegen flag written away from the root package

* class: error — an error, always
* rule: a whole program is compiled as one, every C file of it on the same command line, so a `flags` argument reaches every package in it unless something scopes it — a warning flag naming one diagnostic becomes a `#pragma GCC diagnostic` around the declaring package's own `#include`s, one naming no single diagnostic has no such pragma and is refused, and a codegen flag stays whole-program and is written by the program's root package

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
