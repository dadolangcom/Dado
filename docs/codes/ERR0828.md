# ERR0828: a `#truncate` to a count the compiler can see is negative, which is no length a run can have

* class: error — an error, always
* rule: `#truncate` leaves a run holding the count it is given, so a count the compiler can fold is zero or more; one past the run's length is a trap at run time naming both numbers

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
