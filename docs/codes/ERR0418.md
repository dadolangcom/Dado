# ERR0418: an `@` name that is not one of the ten attributes, or one of them written where none may go

* class: error — an error, always
* rule: `@` is a registered set: an unknown one is refused, and so is a registered one written where none may go

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
