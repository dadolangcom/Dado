# ERR1224: a reload's new code for a class the build does not carry, calling a Dado function the build does not bind or binds with another signature, dropping or changing a method the build's Dado runs or a field it reaches through a handle, or changing a kept field's type

* class: error — an error, always
* rule: a script's new code replaces the running code only when its class is one the build carries, every Dado function it calls is bound in the build with the same signature, every method the build's Dado runs and every field it reads or writes through a handle are kept with their signatures and types, and every other field it shares with the running code keeps its type — so new code checked against a build's manifest (`dadoc --emit=reload --against=<manifest>`) that misses any of these is refused, naming each miss and the rebuild that makes it one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
