# WRN0717: two named failure codes with one value, both reaching one function's caller

* class: warning — a warning, never an error
* rule: a failure is its code and nothing else, so the named constants one function can fail with — its own `fail`s and `else CODE`s and every failure passed on to it — hold different values, or its caller cannot tell them apart; a warning, `--strict` included

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
