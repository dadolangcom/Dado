# ERR0529: a signal parameter that is a view — `[]T`, `^T`, a string, a `cstring` — or a map or a signal, anywhere inside its type

* class: error — an error, always
* rule: a signal's message outlives its `#emit`, perhaps on another thread, so each parameter is plain data it can copy or a `ref` it takes ownership of, never a view into storage the emitter keeps, a map, or another signal

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
