# ERR0529: a channel parameter that is a view — `[]T`, `^T`, a string, a `cstring` — or a map or a channel, anywhere inside its type

* class: error — an error, always
* rule: a channel's message outlives its `#send`, perhaps on another thread, so each parameter is plain data it can copy or a `ref` it takes ownership of, never a view into storage the sender keeps, a map, or another channel

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
