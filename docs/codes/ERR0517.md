# ERR0517: axes used on a shape whose view has taken one of the eight letters for a slot

* class: error — an error, always
* rule: a view that takes one of the eight axis letters for a slot leaves that shape no axes at all

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
