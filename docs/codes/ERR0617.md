# ERR0617: a slice assignment whose window and source lengths, both known at compile time, differ

* class: error — an error, always
* rule: a slice assignment copies an exact window, so the run assigned has the window's length

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
