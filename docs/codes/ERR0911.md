# ERR0911: a generic binding in a `when` condition, which selection runs too early to know

* class: error — an error, always
* rule: selection runs before checking, so a `when` cannot ask about a binding no call has made yet

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
