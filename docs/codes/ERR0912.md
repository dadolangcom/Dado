# ERR0912: more type values evaluated in one compilation than the cap allows

* class: error — an error, always
* rule: a type value is free at run time and not at compile time, so the number evaluated in one compilation is bounded

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
