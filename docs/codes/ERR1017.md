# ERR1017: `quit` on a target whose OS is `#NONE` or `#WEB`, which has no process to end and nobody to read the status

* class: error — an error, always
* rule: a target with no C library (`#NONE`, `#WEB`) has no process to end and nobody to read a status, so `quit` is refused. A `fail` in `main` is not `quit`: on every target it returns its code to whatever called the entry point — the host on the web, the reset handler on bare metal — and the defers run, so it is not refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
