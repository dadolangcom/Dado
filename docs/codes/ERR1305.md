# ERR1305: a method no DadoScript array, map or string has — another language's spelling, or one DadoScript does not admit — or a method called on a scalar

* class: error — an error, always
* rule: an array's, a map's and a string's methods are the admitted lists — `[]T` 26, `{K: V}` 9, `string` 19, and `decode_utf8` on a `[]byte` — so a method outside them is refused, naming DadoScript's spelling of what was meant or where to write what DadoScript does not have

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
