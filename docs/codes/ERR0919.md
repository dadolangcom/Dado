# ERR0919: a call binding a template outside the domain its header `where` states — the predicate is asked of what this call bound, so the call is what is underlined

* class: error — an error, always
* rule: a `where` states a template's domain and is asked of what the call bound, so a call outside it is refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
