# ERR0917: a `#lower` name in a `when` condition, which is the half of the `#` sigil that promises nothing at compile time

* class: error — an error, always
* rule: the `#` sigil splits by case and only the `#UPPER` half is known before the program runs, so only it selects

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
