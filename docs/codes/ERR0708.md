# ERR0708: a `switch` over a `#` compiler definition, which compares at run time a value the compiler already knew

* class: error — an error, always
* rule: a `switch` is a run-time construct whatever its scrutinee is, so selecting on what the compiler already knew is refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
