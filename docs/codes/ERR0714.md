# ERR0714: `fail`, a `try` that passes a failure on or fails with a code, a `defer!`, or a `defer fail`, in a function not marked failable

* class: error — an error, always
* rule: `fail`, a `try` that passes a failure on, a `try … else CODE` and a `defer!` end a function unsuccessfully, which only a function whose return type carries the `!` mark can do, and a `defer fail` runs only when one does

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
