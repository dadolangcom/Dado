# ERR0827: one call handed both a view into a block and the handle to it, where the callee may move the block and then read or write through the view

* class: error — an error, always
* rule: a call does not hand a callee a view into a block — a pointer, a window or a trait value, the `^self` receiver included — together with a handle to that block, when the callee's summary says it may grow or free the block and then use that view; a callee with no body is not seen here

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
