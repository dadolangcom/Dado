# ERR0725: a failure of another enum, or a plain failure, passed on by a function marked `E!T`

* class: error — an error, always
* rule: a function marked `E!T` passes on only failures of the same `E`, by `try`, `return` or `defer!`; a failure of another enum, or a plain `!` one, is handled where it arrives and failed with a member

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
