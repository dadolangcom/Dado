# ERR1103: a `-D` that does not name one `@const` — a bare name more than one package declares, or one declaration named twice by its two spellings

* class: error — an error, always
* rule: an override names one `@const`, and a bare name is the qualified spelling abbreviated only while it resolves to one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
