# ERR0810: a `using` subject that is not an allocator — the two words `(proc, data)` or an implementer of the `Allocator` trait — so there is nothing for the suite to allocate through

* class: error — an error, always
* rule: `using` shadows the ambient allocator, so its subject has to be one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
