# ERR0918: a `$` arity binder written where no signature can bind it — a `type` body, a package-level declaration or a local, none of which has a call to infer a count from

* class: error — an error, always
* rule: an arity is inferred from the arguments of a call, so a `$` binder belongs to a signature

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
