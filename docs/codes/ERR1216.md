# ERR1216: a `#script_error()` outside the `else` of a `try` over a call into a script that can fail

* class: error — an error, always
* rule: `#script_error()` answers the text of the failure a `try` caught from a script, so it is written only in the `else` of a `try` over `#script_vm`, `#script_new`, a method called through a handle or `#script_reload`, where the code the `else` binds and the text it reads are the same failure's — `#script_run(c)` never fails, so its `else` has none

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
