# ERR1001: a transparent foreign type whose layout has no C spelling

* class: error — an error, always
* rule: a transparent foreign type is laid out the way C laid it out, so a layout C has no spelling for is refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
