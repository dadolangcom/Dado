# ERR1228: an `#assert_raises` naming no function of its package

* class: error — an error, always
* rule: `#assert_raises` names functions of its own package by their bare names — a function with a body this program checks, a generic one by its template's name — so a name its package declares no such function by is refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
