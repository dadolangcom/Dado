# ERR1228: an `#assert_raises` naming no function of its package, or written above something that is not a function or a method

* class: error — an error, always
* rule: `#assert_raises` names functions of its own package by their bare names — a function with a body this program checks, a generic one by its template's name — and written alone on a line it promises the package-level function declared on the line below, or in a `type` body the method declared on the line below, so a name its package declares no such function by, a line above anything but such a function or method, or the list form in a `type` body, is refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
