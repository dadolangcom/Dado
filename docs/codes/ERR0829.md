# ERR0829: the handle a growth verb answers, dropped — the run it was handed has moved, and nothing holds the block

* class: error — an error, always
* rule: `#append`, `#resize` and `#reserve` answer the run's handle and move the run they were handed, so the answer is stored, returned or handed on — never written as a statement on its own or discarded with `_ =`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
