# WRN1207: a script's argument narrowed into a Dado parameter, under `--strict`, where it is not a constant that fits

* class: warning — a warning, never an error
* rule: a script's `int` passed to a narrower Dado integer wraps and its `float` passed to an `f32` rounds, as Dado's written conversion does — an array's elements as a scalar's — and that is never an error; under `--strict` it is a warning wherever the argument is not a constant the parameter holds exactly, or a literal whose every element is one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
