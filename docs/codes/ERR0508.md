# ERR0508: an enum value that arrived by counting collides with a written one

* class: error — an error, always
* rule: two enum members share a value only when both write it, so a counted value may not land on a written one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
