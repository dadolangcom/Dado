# ERR0902: a division or remainder by a zero the compiler can see

* class: error — an error, always
* rule: an integer division or remainder by zero stops the program at run time, naming the line; one the compiler can see is refused at compile time, as is a division by zero in any constant expression, which has no runtime to trap in

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
