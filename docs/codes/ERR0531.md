# ERR0531: a copy of a value holding a channel — an assignment, a by-value parameter or return, a binding or a walk by value

* class: error — an error, always
* rule: a channel is one mailbox with one address that producers and its consumer share, so a value holding one is never copied — not assigned, passed or returned by value, walked by value or bound from a copy — and is reached through `^T` or `ref T`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
