# WRN0923: a package the program reaches that was written against POSIX with no `when #OS` arm for a non-POSIX target — `#WINDOWS` — so its C calls what that platform's C library does not promise

* class: warning — a warning, never an error
* rule: a target whose operating system is hosted and not POSIX is told, as a warning, of each package the program reaches that selected a POSIX header or feature-test macro and wrote no arm for that system

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
