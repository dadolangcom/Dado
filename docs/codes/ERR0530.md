# ERR0530: a `ref` in the message of a `#signal(latest)`

* class: error — an error, always
* rule: a `latest` signal overwrites what nobody took, so its message holds no `ref`: dropping one would leak it and freeing one is a side effect nothing wrote

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
