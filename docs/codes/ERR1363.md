# ERR1363: a Dado method connected with a pointer that is not the `^T` its `^self` takes

* class: error — an error, always
* rule: a method bound to a pointer is called through that pointer, so the pointer is the `^T` its `^self` takes

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
