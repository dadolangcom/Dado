# ERR0106: string literal is never closed

* class: error — an error, always
* rule: a `"…"` string literal closes on the line that opened it, and a `"""` one closes on a line of its own before the end of the file

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
