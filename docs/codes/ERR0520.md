# ERR0520: a slot of a contract that is not a function reference, so nothing could be called through it

* class: error — an error, always
* rule: a contract is the tuple of operations a call reaches through, so every slot of one is a function reference

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
