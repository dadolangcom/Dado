# ERR1209: a `#script_new`, `#script_stop`, `#script_pause`, `#script_resume`, `#script_is_running`, `#script_is_paused` or `#script_reload` given something other than a VM, or a `#script_vm` written with `using`

* class: error — an error, always
* rule: a VM is the engine a program's scripts run in, made by `#script_vm` and typed `VM`, so `#script_new`'s first argument and the VM-wide verbs — `#script_stop`, `#script_pause`, `#script_resume`, `#script_is_running`, `#script_is_paused` and `#script_reload` — take a VM, never an instance's handle or another value; and `#script_vm`'s own allocator is its argument, never a `using` around it (row 1.2)

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
