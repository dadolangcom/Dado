# ERR1303: a `.dados` file with no header whose basename is not an identifier, so it names no class, or an imported directory of scripts alone whose name is no identifier

* class: error — an error, always
* rule: a script's class is named by its header, `class Name`, or else by its file's basename, which then has to be an identifier; and since a script names no package, an imported directory holding only scripts is the package named by the directory, whose name then has to be an identifier too

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
