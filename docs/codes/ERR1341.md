# ERR1341: a script of a JavaScript library package that calls a Dado function or loads a script by its path

* class: error — an error, always
* rule: a JavaScript library — the package `--emit=js-package` writes — runs in a JavaScript host with no Dado in it, so its scripts call no Dado function and load no script by its path — both are what a Dado host answers — until Dado's half has a JavaScript-host form; each call is refused, naming the function or the load and what to write in DadoScript instead

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
