# ERR1201: an argument whose type does not cross into the parameter it is passed to — a `#script_run` argument into a DadoScript parameter, or a script's argument into a Dado function's

* class: error — an error, always
* rule: a value crosses between Dado and a script only as a type both sides hold — into a script's `int` any integer, a `u64` by its bits; into a `float` an `f32` or `f64`; a `bool`; into a `string` a copy of a `string8` or a `ref([]char8)`; into a `[]T` a slice, `ref([]U)` or array whose elements cross into `T`; into a fixed array `[N]T` a Dado array or same-typed shape of `N` slots, each crossing; into a tuple a Dado tuple of as many slots, each crossing; into a class's instance a handle of that class; and the other way a script's `int` into any sized integer, its `float` into an `f32` or `f64` (a literal number too), a `bool`, a `string` into a `string8` or a one-code-point `char32`, and an array, fixed array or tuple whose elements cross into a Dado slice, array or tuple, a fixed array of the array's length — so an argument of any other type, or with any element of another type, is refused where it crosses, naming the part and the conversion that makes it one: a `float` never becomes an integer without `int(x)`, nor an `int` value a float without `float(x)`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
