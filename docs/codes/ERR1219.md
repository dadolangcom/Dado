# ERR1219: a script's field or answer whose DadoScript type has no Dado side, or an instance crossing beside a container

* class: error — an error, always
* rule: only what both sides hold crosses into Dado from a script's instance: a field or an answer of a scalar, of an array or tuple of scalars (an answer only), or of a class Dado names — so an `any`, an enum, a trait value or an inner class of another package's script, and a field holding a container, are refused where Dado reaches them, naming a method to write that answers values that cross; and an instance crossing in the same run as an array or a tuple is not built yet

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
