# ERR1204: a method called through a handle that the class lacks or given the wrong number of arguments, a `#script_new` giving `init` the wrong number, or a `#script_run` of a class with no `ready` or giving `ready` the wrong number

* class: error — an error, always
* rule: a method called through a handle names a method of the handle's class and gives it as many arguments as it takes, a `#script_new` gives the class's `init` as many as it takes, and `#script_run(c, ..args)` runs the class's `ready`, so its class declares one, and gives it as many as it takes

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
