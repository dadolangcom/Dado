# ERR0901: an initializer that is not a compile-time constant

* class: error — an error, always
* rule: a `const` initializer folds at compile time, and one that cannot is refused rather than deferred

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
