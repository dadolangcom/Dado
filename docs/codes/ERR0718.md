# ERR0718: a `case a, b:` list in a `switch` over a union, whose arm binds one member's type

* class: error — an error, always
* rule: an arm over a union narrows the value to one member's type, so it names one member and a `case a, b:` list is written only over a value

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
