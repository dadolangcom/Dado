# ERR0808: a `#stack` rung where there is no compound literal to emit — as a value, handed to a callee, on a verb that sizes its block at run time or allocates through the allocator's `proc`, or on a count only known at run time

* class: error — an error, always
* rule: `#stack` is written only where the allocation lowers to a compound literal at the call: last on `#new(T, …)`, or on `#make([]T, N, …)` with a count the compiler knows

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
