# ERR1223: a `#script_reload` in a release build that does not enable reload

* class: error — an error, always
* rule: a release build carries no table of what it bound and swaps no code under a running script, so `#script_reload` is refused in one unless the build enables reload with `--reload`; a build that is not a release one always may reload

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
