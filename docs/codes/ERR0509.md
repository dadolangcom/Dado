# ERR0509: an enum backed by something that is not an integer

* class: error — an error, always
* rule: member values are counted only over an integer backing; under any other every member writes its own

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
