# ERR1350: `slots(v)` outside a `for` header, over a value that is no instance, or where a member or function of that name could mean it; or `T.names()` where an inner class named `names` could mean it

* class: error — an error, always
* rule: a script asks a type for its slot names with `T.names()` — a class, an enum or a Dado declaration it names, with no arguments — and walks an instance's slots only as a `for` header, `for name, value in slots(v)`, over an instance of a class, a trait's value or an `any`, so `slots(v)` is no value, walks nothing else, and is refused where the class's own member or a Dado function named `slots` could mean it, as `T.names()` is where an inner class named `names` could

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
