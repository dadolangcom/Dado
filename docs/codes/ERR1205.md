# ERR1205: a `#script_*` verb in a build that can run no script — a `#NONE` target, or no DadoScript runtime in the compilation

* class: error — an error, always
* rule: a script runs on an engine and the DadoScript runtime: natively the engine a build links, which needs a hosted C library, and on the web the page's own JavaScript engine; a `#NONE` target has neither, and a compilation that does not hold `core:script` has no runtime to run one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
