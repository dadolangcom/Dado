# ERR0716: a `try` over something that is neither a failable call nor a map read, one that would throw its value away, or one whose `else` is malformed, binds over a constant, translates a code, or lets a declared binding be read on the failing path; or a `defer!` over anything but one failable call answering no value

* class: error — an error, always
* rule: `try` stands at the start of a statement over one failable call or map read — in a declaration, an assignment with `=`, or alone when it answers no value — and its `else` is a suite, `else:` or `else NAME:` binding the code to a new name, or a code, `else CODE`, which fails when a map read or a create verb finds nothing; a suite after a declaration leaves the scope; `defer!` holds one failable call made alone

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
