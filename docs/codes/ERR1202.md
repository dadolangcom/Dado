# ERR1202: a `#script_new` or `#script_reload` naming no DadoScript class, or a `#script_run` given something other than an instance's handle

* class: error — an error, always
* rule: a script's class is named — `#script_new(vm, Goblin)` for a class of this package, `#script_new(vm, npc.Goblin)` for one of an imported package, and so for `#script_reload` — never by a path or a Dado type, and `#script_run`, `#delete` of an instance and a member call take a handle `#script_new` answered

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
