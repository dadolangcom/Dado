# WRN0826: a copy of storage on this frame kept where it outlives the frame, which may point at other storage on the frame through a write the compiler cannot follow

* class: warning — a warning, never an error
* rule: within one function, a copy of storage on the function's frame kept where it outlives the frame — by a callee that keeps what a pointer to it points at — does not point at other storage on the frame through a write the compiler cannot follow: a call it cannot read (a function value, a `foreign` function) handed a pointer to that storage beside a view of the frame, or a store through a pointer converted from `rawptr`; a warning, `--strict` included, since the write may not have happened — a copy the compiler can follow to the frame is `ERR0826`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
