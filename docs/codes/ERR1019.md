# ERR1019: a `#c.char` given to a Dado operator or to `print`, neither of which has an answer while its signedness is C's to choose — `#c.schar` and `#c.uchar` say which is meant and both convert

* class: error — an error, always
* rule: C leaves plain `char`'s signedness to the implementation, so Dado has no arithmetic and no rendering for one until a conversion says which was meant

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
