# ERR1320: a JavaScript module bound under no identifier or imported unqualified, a module importing a package manager's name, or a `foreign "x.js":` declaration a script cannot call

* class: error — an error, always
* rule: a script reaches JavaScript through `import "x.js"`, which binds the module's namespace — qualified, since its members are `any` and no declaration names them — under the file's name or an alias, and `foreign "x.js":`, which declares its functions with the types a script holds; so a binding is an identifier, a declared type is one JavaScript can hand back (no class of a script's), a declared name is no method of the class, and every module the file imports is a file found from it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
