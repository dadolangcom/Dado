# ERR1032: a `foreign` block naming a header outside C's freestanding set, reached live on a target whose `#OS` is `#NONE` or `#WEB`

* class: error — an error, always
* rule: a target with no C library (`#NONE`, `#WEB`) provides only the nine headers C gives a freestanding implementation, so a `foreign` block naming any other `<header>` is refused when such a build reaches it — unless a `when` folds the block away or `@freestanding` says the program supplies that header. On `#WEB`, files and the environment reach a program through DadoScript instead. The refusal stands for the refused package's other errors on that target, which follow from the C library it was written against: they are counted on it, not reported

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
