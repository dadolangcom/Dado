# ERR1002: a foreign type declared `@incomplete` held by value rather than behind a pointer

* class: error — an error, always
* rule: a foreign type declared `@incomplete` is one the C header never defines, so C refuses a value of one and so does Dado: it is held behind a pointer and never by value

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
