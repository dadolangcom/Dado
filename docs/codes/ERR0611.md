# ERR0611: a call to a failable function that nothing handles

* class: error — an error, always
* rule: a failable call has no value to store or discard, so it is made by `try` at the start of a statement, or passed on whole by a failable function's `return`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
