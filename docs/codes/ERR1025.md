# ERR1025: an address or a window that would reach one type through its two C spellings — `&` on a member list a transparent `foreign` type wrote with a name, or a pointer, window or reference to a restatement standing where one to the shape it restates is wanted, or the reverse

* class: error — an error, always
* rule: a transparent `foreign` type is one type with the Dado shape it restates, and the header and Dado spell that one type as two C types — the header's name and Dado's own, or for a member list the header wrote with a name and left unnamed in C, one Dado declares — so a whole value crosses between the two spellings by copy, and an operation whose answer would be one C name for both, an address or a window, is refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
