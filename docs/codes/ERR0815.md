# ERR0815: a `#no_bounds` written where there is no bound to waive — a one-slot shape's sole position is `0`, so its check is what the subscript means rather than a guard around it, and a map read is total

* class: error — an error, always
* rule: `#no_bounds` waives a subscript's bounds check, so it is written on a subscript that has a bound to be loose about

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
