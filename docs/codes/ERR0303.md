# ERR0303: an import path names no package, or a JavaScript path no file

* class: error — an error, always
* rule: an import path names a package that exists, found in a collection or beside this file; a JavaScript path — an import's or a `foreign` block's, `.js` or `.mjs` — names a file the same way, and each module that file imports is a file beside it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
