# ERR1220: a Dado function a script passes a function to that keeps its bare function-reference parameter past the call

* class: error — an error, always
* rule: a script's function passed to a Dado function's bare function-reference parameter is called through a static trampoline that reads it from a slot filled only for the call, so the Dado function may call it during the call and not keep it — storing it, returning it, or handing it to a function that does, as the escape check sees it — and one that keeps it is refused where it does, naming the repair: take a context, a `(proc, rawptr data)` pair, which carries the script's function past the call

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
