# ERR0803: a view, a walk or a handle used after the block under it may have moved or been taken back — `#append`, `#resize`, `#reserve`, `#delete`, an insert, rebinding the handle, handing a `^` to it to a call, `#emit`ting the `ref` to a signal, draining the signal a `#peek` lent it from, or ending the region it was minted in (a scratch frame rolled back, an arena's mark ended, an arena destroyed) — on some path through the same function

* class: error — an error, always
* rule: within one function, a view or a walk minted from a `ref` or a map — or a second handle copied from one — is not used after a statement that may move or free the block under it, a `defer` counting where it runs, at its scope's exit, and a returned view or handle counting as used after every `defer` still pending; a move a callee makes is read from its summary, and one made inside a callee with no body — a `foreign` function, a function value — is not seen here; and a block minted from a region the compiler can name — `core:runtime`'s scratch, a `core:mem/arena` arena — is not used after the scratch frame, the arena mark or the arena it lies in is rolled back, ended or destroyed, whether this function does that, a helper that closes the frame does, or a callee that grows the handle inside a scratch frame it rolls back does

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
