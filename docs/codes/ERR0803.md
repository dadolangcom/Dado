# ERR0803: a view, a pointer or a handle read after the block under it was freed on every path through the same function

* class: error — an error, always
* rule: within one function, a view or a pointer minted from a `ref` held in this frame — or a second handle copied from one — is not accessed after a statement that frees that block on every path to the access, when all of these hold: the access reads or writes the block (a subscript, a `^`, a slot read through a pointer, a `for` over it, `#copy` of it) or frees it again; the function never takes the address of the handle, of the value accessed or of any binding it was copied through, anywhere; the free is a `#delete` of the handle, a `defer` that does one counting where it runs, or a call to a function whose body frees the handle it is handed by value on every way out; and the block was minted on an allocator that frees — `#heap`, or the default allocator outside every `using` in a program's `main` that is not written `public` or `export` and that nothing calls or names — on a target with a heap (never `#NONE`). Handing the value to a call, comparing it, measuring it, and every read that is not proven so, is `WRN0803`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
