# ERR0916: a `#LEN` whose operand's count lives in the value rather than in its type — a window's length is a run-time fact and `#len` is what asks for it

* class: error — an error, always
* rule: `#LEN` asserts the count is in the type; where it lives in the value, `#len` is what asks

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
