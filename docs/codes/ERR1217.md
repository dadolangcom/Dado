# ERR1217: an `on_error:` that is not `script.QUIT` or `script.CONTINUE`

* class: error — an error, always
* rule: `#script_vm`'s `on_error:` is the VM's failure policy, and folds to one of `core:script`'s two: `script.QUIT`, under which an untried call through a handle that fails ends the program, or `script.CONTINUE`, under which it answers its zero value and the program goes on

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
