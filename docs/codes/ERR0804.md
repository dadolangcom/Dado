# ERR0804: an assignment to `#default`, which is immutable within a scope — a nested suite shadows it with `using`, and nothing rebinds it

* class: error — an error, always
* rule: `#default` is a name the compiler owns and not storage a program holds, so a scope shadows it and nothing assigns to it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
