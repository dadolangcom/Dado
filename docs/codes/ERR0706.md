# ERR0706: a `case` arm whose value an earlier arm already matched

* class: error — an error, always
* rule: a `switch` takes the first arm that matches, so an arm an earlier one already covers could never run

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
