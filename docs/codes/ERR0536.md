# ERR0536: a declaration taking a trait on without a method the trait prescribes, or with a different signature or receiver

* class: error — an error, always
* rule: a declaration that takes a trait on has every method the trait prescribes, with the trait's signature — `Self` read as the declaration — and the same receiver, in its own body or promoted into it; a default fills one it does not write

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
