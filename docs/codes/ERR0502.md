# ERR0502: array length is not a compile-time integer

* class: error — an error, always
* rule: an array length is a count the compiler already knows, written in one of the spellings the language closes the list at

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
