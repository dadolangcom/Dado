# ERR0824: a place read after its `ref` moved into a signal by `#emit`, on a path where the `#emit` succeeded

* class: error — an error, always
* rule: within one function, a `ref` handed to a successful `#emit` belongs to the signal's consumer, so the place it was read from holds nil and is not read again before it is written; on the `else` path it is still the producer's

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
