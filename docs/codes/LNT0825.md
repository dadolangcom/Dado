# LNT0825: one package-level signal walked from two thread roots

* class: lint — a warning, an error under `--strict`
* rule: a signal has one consumer thread, so two thread roots — `main` and each function handed to `core:threads.spawn` — do not both reach a walk of one package-level signal the program never `#release`s; a warning while writing and an error under `--strict`, because a hand-off the compiler cannot see is legal

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
