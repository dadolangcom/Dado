# ERR0411: a name that starts with the prefix emitted names use

* class: error — an error, always
* rule: the prefix every emitted name starts with belongs to the compiler, so no program name starts with it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
