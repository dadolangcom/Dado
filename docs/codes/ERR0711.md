# ERR0711: `fallthrough` somewhere it cannot stand — not the last statement of a `case` body, or not in a `switch` at all

* class: error — an error, always
* rule: `fallthrough` stands as the last statement of a `case` body and nowhere else

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
