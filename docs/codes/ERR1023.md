# ERR1023: a bitfield width written where C has none or with a base C cannot lay out in bits, a value that does not fit one, or an operation C refuses on one

* class: error — an error, always
* rule: `T name : W` gives a member of a transparent `foreign` struct the width in bits C lays it out in, so the base is a type C lays out in bits, the width fits inside it, an unnamed field is `T _ : W` or C's zero-width `T : 0`, a stored value fits the width, and what C refuses of a bitfield — its address and its `sizeof` — is refused here

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
