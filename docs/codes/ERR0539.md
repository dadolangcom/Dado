# ERR0539: a number no value of its type represents

* class: error — an error, always
* rule: a number with no value in its type is refused — an integer past 64 bits, a constant whose folding overflows the compiler's arithmetic, a float that is infinite or not a number in its type, a script's failure code past `i32`, a count past what it counts — since no conversion could keep it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
