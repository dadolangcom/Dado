# ERR0930: a `#static_assert` whose condition folds to `false` in this build

* class: error — an error, always
* rule: a `#static_assert` states a build invariant, folded as a `when` condition is, and a build in which it folds to `false` is refused with the author's message and where each operand's value came from

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
