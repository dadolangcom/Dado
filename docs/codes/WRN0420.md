# WRN0420: a type, enum or trait named like one of the language's own types, so its own package never names it plainly

* class: warning — a warning, never an error
* rule: a type, enum or trait declared under a type name the language itself spells is reached only by a side door — another package's qualified name, the enum's members, the trait's `using` or `^` — since every plain mention of that name means the language's type; a warning, `--strict` included

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
