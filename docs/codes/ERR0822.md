# ERR0822: a function whose body names `#caller`, taken as a value or exported, where no Dado call site is there to hand it the caller's allocator

* class: error — an error, always
* rule: a function whose body names `#caller` is reached only by a direct call written in Dado, which is what hands it the caller's allocator: it is not taken as a value and not exported

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
