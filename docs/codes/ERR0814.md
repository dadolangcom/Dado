# ERR0814: `#cap`, `#append` or `#reserve` written over something that has no capacity distinct from its length — a fixed array, a borrow, a single-element reference or a map

* class: error — an error, always
* rule: capacity is asked only of something whose capacity is distinct from its length

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
