# ERR0712: `fallthrough` in the last `case` arm or in an `else`, where there is no next arm to fall into

* class: error — an error, always
* rule: `fallthrough` transfers to the next `case` arm, so there has to be one — and an `else` is not it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
