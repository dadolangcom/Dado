# ERR1004: a render the freestanding header set has nowhere to send

* class: error — an error, always
* rule: a target with no C library and no runtime console (`#NONE`) has no stream to render into, so a render with nowhere to go is refused rather than emitted; `#WEB` has no C library and does have the console its runtime supplies, so it renders

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
