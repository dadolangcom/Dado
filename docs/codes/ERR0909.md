# ERR0909: a `$T` bound to a shape C has no name for, so the instantiation it asks for could not be emitted

* class: error — an error, always
* rule: an instantiation's C name is built out of what it bound, so a shape C cannot name is one no template instantiates at

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
