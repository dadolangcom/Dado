# LNT0731: a `switch` over an `enum` whose arms leave a declared member unnamed

* class: lint — a warning, an error under `--strict`
* rule: a `switch` over an `enum` names every declared member in an arm, so adding a member shows every `switch` it reaches — a warning while writing and an error under `--strict`; the `else` stays, because a value need not be a member, unless the value is a failure an `E!T` call answered

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
