# LNT0505: a number that does not fit the integer type it is written for, and wraps

* class: lint — a warning, an error under `--strict`
* rule: a number written for an integer type fits it, or is written as the conversion that wraps it — `u8(300)`; one that does not fit wraps as that conversion would — a warning while writing and an error under `--strict`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
