# ERR1304: an `init` that returns a value, a `ready` that answers something other than an `int` or nothing, or a `reloaded` that takes parameters or answers a value

* class: error — an error, always
* rule: the harness calls `init`, `ready` and `reloaded` into a class by name, so their shapes are fixed: `init` returns nothing, `ready` — the entry `#script_run` runs, as a program's `main` is run — answers an `int` or nothing, each taking the arguments its verb passes after the class or the handle, and `reloaded` takes nothing and answers nothing

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
