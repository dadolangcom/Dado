# ERR0310: a declaration whose name an `import .` of its file already makes bare

* class: error — an error, always
* rule: a declaration does not take a name an unqualified import of its file already spells bare, so the import is never shadowed

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
