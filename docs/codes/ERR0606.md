# ERR0606: a value with no place where a place is needed — an assignment, an address, a `^self` receiver or a trait value

* class: error — an error, always
* rule: what is assigned to, addressed, written through `^self` or viewed by a trait value is a place — a name, a slot of one, or a position in one — and a temporary or a constant is none

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
