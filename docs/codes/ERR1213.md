# ERR1213: a `receive` given other than a package-level channel and a `void` function over its message's fields

* class: error — an error, always
* rule: a script binds a handler to a channel by `receive(ch, handler)`: the first argument names a package-level channel a Dado file declares — `hits` of the script's package, `lib.hits` of an import — never a value the script holds, and the second is a function the runtime calls with each message, a `void` over the message's fields as they cross into a script, so `receive` given another count of arguments, a name that is no channel, or a handler of another type is refused, naming the channel's handler type

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
