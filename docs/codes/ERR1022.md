# ERR1022: a `[_]T` written somewhere C has no flexible array member, or an operation on one whose answer would be the length nobody stated

* class: error — an error, always
* rule: `[_]T` is the last member of a transparent `foreign` struct and its length is in neither the type nor the value, so the struct's shape is its header, nothing that needs the tail's length is answered, and every position C refuses one in is refused here

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
