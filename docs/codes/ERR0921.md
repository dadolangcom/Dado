# ERR0921: a `contract` written where a contract value would have to be stored or chosen while the program runs — it is compile-time known and erased, a `const` is where one lives, and `type` over the same shape is the run-time form

* class: error — an error, always
* rule: a contract value is compile-time known and erased, so nothing holds one or chooses between them while the program runs

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
