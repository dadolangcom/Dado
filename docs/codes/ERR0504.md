# ERR0504: a value of one shape where another is required

* class: error — an error, always
* rule: a value is of the shape its position requires, and only a value-preserving widening is supplied to fit

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
