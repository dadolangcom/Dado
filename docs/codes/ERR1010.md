# ERR1010: a `define` clause whose text is not a macro definition — `NAME` or `NAME=replacement`

* class: error — an error, always
* rule: a `define` clause is a macro definition — a name, or a name and its replacement

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
