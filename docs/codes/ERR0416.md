# ERR0416: a name that is not a member of the union it is spelled against

* class: error — an error, always
* rule: a union's members are alternatives and not parts, so one is named as a member and read through the guarded read

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
