# ERR0601: an argument list fills a different number of slots than the parameter list has

* class: error — an error, always
* rule: an argument list fills every slot of the parameter list and no more

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
