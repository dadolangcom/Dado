# ERR0206: a variadic parameter written where one cannot be, or reached by a route its calling convention has no answer for

* class: error — an error, always
* rule: a variadic pack collects the rest of the argument list, so nothing follows it and no name fills it, and a pack whose elements each have a type of their own is not a value — a body writes it as a count, as the arguments of a call, or as a loop over its elements

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
