# ERR0720: a `for … in` over a signal itself rather than over `#peek` or `#drain` of it

* class: error — an error, always
* rule: a signal is consumed by a walk that says whether it takes what it sees, so a `for` walks `#peek(sig)` or `#drain(sig)` and never the signal itself

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
