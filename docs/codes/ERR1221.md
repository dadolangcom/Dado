# ERR1221: a call from Dado into a script with more than 16 arguments

* class: error — an error, always
* rule: one call from Dado into a script (a method through a handle, `#script_new` giving `init` its arguments, `#script_run` giving `ready` its, or a script's package function) carries at most 16 arguments, the table the runtime makes one call's arguments in, so a call of a script method that takes more is refused where it is written; a script calling the method itself is not limited

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
