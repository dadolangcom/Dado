# ERR0540: a string literal holding a NUL where a `cstring` is wanted

* class: error — an error, always
* rule: a `cstring` ends at its first NUL, so a literal made one holds none: C would read the text before it and never the rest, where a `string8`, `string16` or `string32` counts its length and holds the NUL as text

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
