# ERR0805: a spelling the language has retired, written where its replacement belongs — the message names the repair

* class: error — an error, always
* rule: a retired spelling is written as its replacement, and the message names the repair

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
