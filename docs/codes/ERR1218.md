# ERR1218: a member of a script's instance named through its handle that the class does not have, or used as no field or method is

* class: error — an error, always
* rule: Dado reaches a script's instance through its handle by the class's own members — `g.hp` reads a public field, `g.hp = v` writes one by itself, and `g.hit(3)` calls a method with its arguments in order — so a name the class does not declare, a field called or a method read, a compound assignment (two runs), a named argument (a script's sinks are scoped with `using` after the call, or set on `#script_vm`), and a field's address or its place in a group assignment (it lives in the engine) are refused, naming what to write

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
