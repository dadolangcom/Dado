# ERR1340: an `export` in DadoScript that publishes a type with no declaration spelling, a class that is not exported, an inner class or generic method, a name twice, or a method reading `self` of a class that is not exported

* class: error — an error, always
* rule: `export` in DadoScript publishes a class — its constructor, its public methods and fields — and a method that reads no `self` as a function, to a JavaScript caller, through a TypeScript declaration of each; so every type a published signature names has a declaration's spelling — a scalar, `any`, an array, a map, a tuple, an enum, a function type over those, `Error`, `Location`, an `async T` answered, or a class that is itself exported — no two published names meet, an inner class or a generic method is not published, and an `export` on a member of a class that is not exported marks a method that reads no `self`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
