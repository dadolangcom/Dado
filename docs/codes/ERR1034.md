# ERR1034: a page template (`--html=`) whose `dado:` markers are missing, unknown, repeated or placed where their output cannot work

* class: error — an error, always
* rule: a web build's page is the author's HTML with markers — comments reading `dado:NAME` — the build replaces, so a template names each marker it uses once, among `dado:importmap`, `dado:preload`, `dado:loader`, `dado:title` and `dado:base`, holds the two a page cannot run without — `dado:importmap` and `dado:loader` — and puts each where its output works: between tags, never inside a `<script>`, `<style>`, `<template>`, `<textarea>` or `<title>` body, `dado:importmap` before any module script and before `dado:preload` and `dado:loader`, and `dado:base` before every marker that writes a URL

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
