# ERR1208: a Dado declaration named in a script whose type does not cross, a construction of one that is no shape, or a write to a slot of one a script holds as a tuple

* class: error — an error, always
* rule: a script names a Dado declaration — `Vec2` of its package, `entities.Vec2` of an import — as a view over the type it crosses as: a shape whose slots share a type is a script's `[]T` and one of mixed slots a tuple, interchangeable with those, and the view reads, writes and constructs its slots by name; so a declaration whose type does not cross is not named, one that is no shape is not constructed, and a slot of a shape a script holds as a tuple is never written in place

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
