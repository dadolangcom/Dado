# ERR1208: a Dado declaration named in a script whose type does not cross, a construction of one that is no shape, a write to a slot of one a script holds as a tuple, or a Dado constant a script reads that cannot be written into it

* class: error — an error, always
* rule: a script names a Dado declaration — `Vec2` of its package, `entities.Vec2` of an import — as a view over the type it crosses as: a shape whose slots share a type is a script's fixed array `[N]T` and one of mixed slots a tuple, interchangeable with those, and the view reads, writes and constructs its slots by name; so a declaration whose type does not cross is not named, one that is no shape is not constructed, and a slot of a shape a script holds as a tuple of mixed slots is never written in place; and a script reads a Dado constant — `KIND` of its package, `lib.KIND` of an import — interned, its folded value written where it is read, so a constant whose type does not cross (an enum among them, until it crosses as a script's enum), one whose value C supplies (`foreign`), or one holding a function or a type is refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
