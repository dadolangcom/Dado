# ERR0724: a `fail` in a function marked `E!T` whose code is not an `E`, or is a constant that is no member of `E`

* class: error — an error, always
* rule: a function marked `E!T` fails only with an `E`, so a caller binding the failure as `E` holds a member: a code of another type, or a constant that is no member of `E`, is proven wrong where it is written; a value of `E` that does not fold is accepted, and a sanitized build checks it is a member where it fails

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
