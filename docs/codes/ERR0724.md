# ERR0724: a `fail` in a function marked `E!T` whose code is not known to be a member of `E`

* class: error — an error, always
* rule: a function marked `E!T` fails only with what is known to be a member of `E` — a member, a constant that folds to one, or the failure an `else` bound from a call failing with `E` — so a caller binding the failure as `E` holds a member

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
