# ERR1211: a `using out:` or `using err:` after a call that runs no script

* class: error — an error, always
* rule: a `using` scopes a script's sinks — `out:`, where its `print` and `println` write, and `err:`, where a failure's text goes — over the script calls in its extent: after a call, that call must be one into a script (a method called through a handle, `#script_run`, `#script_new` or `#script_reload`), and over a suite, every script call inside writes to them; so a sink after a Dado function's call (Dado's own output, `core:fmt`, never reads a script's sinks — write the block form around it), after `#script_vm` (whose own `out:` and `err:` set the VM's) or after a verb that runs no script code is refused, naming what to write

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
