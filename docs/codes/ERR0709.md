# ERR0709: a `&` loop binding with no storage to address — a range, a string, an index, a map key, or a subject that is not a place

* class: error — an error, always
* rule: `&` binds where the loop walks storage the body may write, and is refused everywhere else

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
