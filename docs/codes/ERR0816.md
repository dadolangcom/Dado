# ERR0816: a constant alignment that is not a power of two — the mask `(p + (n - 1)) & ~(n - 1)` is the alignment only for one, and a computed alignment is the programmer's word because the allocator interface carries one at run time

* class: error — an error, always
* rule: `#align_forward` rounds up with a mask, so a written alignment is a power of two

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
