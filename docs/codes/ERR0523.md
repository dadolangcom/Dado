# ERR0523: a `!` or `E!` in front of a type written anywhere but a function's return in its signature or a failable function type

* class: error — an error, always
* rule: a failure is never stored, so `!` — alone or as `E!` — marks only a function's return type in its signature and a failable function type, and never the type of a value

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
