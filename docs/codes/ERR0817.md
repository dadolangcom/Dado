# ERR0817: an atomic verb over something that is not a `^i32`, `^u32`, `^i64`, `^u64` or `^rawptr` — a width outside that set becomes a `libatomic` call, which is a link error on a freestanding target rather than a slow program

* class: error — an error, always
* rule: an atomic access is over a `^T` whose width the target can do lock-free

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
