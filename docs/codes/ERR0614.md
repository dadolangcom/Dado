# ERR0614: `#emit`, `#peek`, `#drain` or `#release` over something that is not a signal, or written with named, spliced or missing arguments

* class: error — an error, always
* rule: `#emit`, `#peek`, `#drain` and `#release` act on one signal, so their first argument is a place holding a signal and the rest are what its parameters take

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
