# ERR0715: `fail` with a code that is zero

* class: error — an error, always
* rule: a failure's code is a nonzero `i32` — or a member of `E` in a function marked `E!T` — because zero is what success answers

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
