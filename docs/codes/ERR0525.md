# ERR0525: a slot name or a `view` written over a shape carrying a layout mark, which presents runs rather than slots

* class: error — an error, always
* rule: a layout mark says the shape holds one run per slot, so what it presents by name is a run and not a slot — the axes do not reach it and a `view` has nothing to name; a slot is reached through a subscript, which names an element first

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
