# WRN0527: a folded float→integer conversion whose value the destination does not hold

* class: warning — a warning, never an error
* rule: a float becoming an integer saturates — NaN is 0, and a value at or past either end of the destination's range is that end — at run time and when folded, and a fold that saturated is said as a warning, never an error

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
