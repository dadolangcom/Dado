# ERR0619: a copy into or out of something that is not a run of elements: a string, a map, a pointer or a single value

* class: error — an error, always
* rule: a copy reads and writes runs of elements — arrays, windows and `ref []T` — and text and maps are none

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
