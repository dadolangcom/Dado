# ERR0920: a `where` clause that is not a comptime predicate over the signature's bindings — it names a value, a word the compiler does not own, or nothing the signature binds at all

* class: error — an error, always
* rule: a `where` is a comptime predicate over the signature's own bindings, and answers a `bool`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
