# ERR0813: a `resize`, an `#append`, a `#reserve` or a `#truncate` on a by-value `ref` parameter — the callee changes its own copy of the handle and the caller is left holding the old one

* class: error — an error, always
* rule: a `ref` parameter is the callee's own copy of the handle, so a caller cannot be grown or shortened through it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
