# ERR0813: a `#truncate` on a by-value `ref` parameter — the callee shortens its own copy of the handle and the caller is left holding the old length

* class: error — an error, always
* rule: a `ref` parameter is the callee's own copy of the handle, so a caller's run is not shortened through it; growing one is legal, since the growth verbs answer the handle

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
