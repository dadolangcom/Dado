# ERR1210: a retired script verb: `#script_load`, or `#script_run` given an entry name

* class: error — an error, always
* rule: the script verbs were reshaped by Sam's change request (2026-10-01): the engine is made by `#script_vm` and an instance in it by `#script_new(vm, Class, ..args)`, so `#script_load` is retired; a method is called through the instance's handle, `c.hit(3)`, and `#script_run(c, ..args)` runs its `ready`, so `#script_run(s, "entry", ..args)` — an entry's name where `ready` takes no string — is retired — each is refused naming what replaced it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
