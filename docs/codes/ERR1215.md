# ERR1215: a `#script_stop` with no timeout, or a timeout that is not an integer number of milliseconds

* class: error — an error, always
* rule: `#script_stop(vm, timeout)` always says how long the script has to stop by itself — the milliseconds, an integer of any width, in which its `defer`s run and a `try` reaches the stop — before it is forced, and `0` forces at once, so a stop that forces is written as one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
