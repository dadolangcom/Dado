# ERR1222: a program whose scripts bind handlers to more than 64 channels

* class: error — an error, always
* rule: a program's scripts bind handlers to at most 64 channels, one bit each in a VM's word of receivers, so a program whose script classes `receive` more, counted over every class it declares whether a run reaches it or not, is refused at the `receive` of the first channel past them in the channel directory's order; a channel Dado walks is not counted

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
