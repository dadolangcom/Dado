# ERR0207: a slot of a destructure written without parentheses that ends without a name

* class: error — an error, always
* rule: every slot of a destructure written without parentheses is a name; `_` binds one to nothing

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
