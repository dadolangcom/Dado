# ERR1028: a `@c_body` written where the compiler emits no C for the declaration under it, or one whose C reaches for a Dado local's emitted name

* class: error — an error, always
* rule: `@c_body("…")` places verbatim C where the compiler has somewhere to put it and something to prune it with, so it goes on a declaration this translation unit emits — a `private` package-level variable, whose C lands at file scope, or a local, whose C lands as statements in that body — and the only names it may reach Dado by are the ones the emitter promises, which the mangling of a local is not

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
