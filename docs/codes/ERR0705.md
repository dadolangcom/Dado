# ERR0705: a `switch` with no `else` arm over a value that cannot promise exhaustiveness, or over a closed failure whose arms leave a member out

* class: error — an error, always
* rule: a `switch` needs an `else` unless its arms name every member of something closed by construction: a union's discriminant, or the failure an `else` bound from a call to a function marked `E!T`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
