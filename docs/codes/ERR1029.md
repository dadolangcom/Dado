# ERR1029: a `foreign` type whose C name is the one this compiler's mangling gives a shape the program holds, or a `foreign` function whose C name the function mangling can produce — two different things the emitted C would have to reach by one name

* class: error — an error, always
* rule: the emitted C reaches what this compiler named by the name this compiler's mangling gives it, so a `foreign` type may not be declared under one of those names while the program holds the shape it belongs to, and a `foreign` function may not be declared under any name the function mangling can produce

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
