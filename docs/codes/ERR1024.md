# ERR1024: a C union declared some other way, or an operation on one whose answer would be the discriminant C does not carry

* class: error — an error, always
* rule: `cunion X: (…)` restates C's non-discriminated union, so it is the one union a `foreign` block declares and the only spelling of one: its members share a storage and are read and written by name with no guard, a value is built from exactly one member chosen by its type, and everything that would need a tag C never sent — a `switch`, a guarded read and `print` — is refused

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
