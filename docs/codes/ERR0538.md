# ERR0538: a generic `type` named without its arguments or with the wrong number of them, or declared embedding its binder or holding a signal no instantiation could own alone

* class: error — an error, always
* rule: a generic `type` names a type only with one type written per binder, and declares only what every instantiation of it can share

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
