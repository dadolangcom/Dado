# ERR0311: `imports:` or `project:` written in a package fetched into an `imports` location

* class: error — an error, always
* rule: a fetched package is complete: what it needs it bundles and imports by a relative path, so `imports:` and `project:`, which answer from the project that fetched it, are written only outside an `imports` location

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
