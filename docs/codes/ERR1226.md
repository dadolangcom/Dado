# ERR1226: a Dado call of a script's package function that names no published function, names two, or gives it what a function by its package does not take

* class: error — an error, always
* rule: Dado calls a script's package function by its package, `pkg.f(..args)`: an `export` method of one of the package's classes that reaches no `self`, named by one class alone, given as many arguments as it takes, in order, each and its answer one of a script's scalars — `int`, `float`, `bool`, `string` — so a method not written `export`, one that reaches `self`, a name two classes publish, a named argument, a wrong count, and a container or an instance crossing are refused, naming the repair: publish it, pass what it reads as parameters, or call it through a handle

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
