# ERR0537: a value converted to a trait value whose type is no declaration, or a declaration that does not take the trait on

* class: error — an error, always
* rule: a trait value is made from a value whose type is a declaration that takes the trait on with `using`, or from a value of a trait that extends it; a shape written out implements nothing

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
