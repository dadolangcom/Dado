# ERR0723: an `E!T` whose `E` is not an enum, is a C enum, or is backed by something other than `i32`, or one on a `foreign` function

* class: error — an error, always
* rule: the enum in front of a failure's `!` is a Dado `enum` or `distinct enum` backed by `i32`, because a failure is an `i32` code; a member equal to zero may be declared and is never a failure; a `foreign` function names none, because what C answers is not checked

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
