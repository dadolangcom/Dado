# ERR1225: a DadoScript feature a web build cannot run — `#script_reload`, `Script.load`, a call from Dado of an `async` method, or `#script_pause` single-threaded

* class: error — an error, always
* rule: a DadoScript feature a web build cannot run is refused where it is written: on the web a script runs on the page's own engine, which evaluates no code from a string under a strict Content-Security-Policy, settles a promise only once the wasm module has returned, and in a single-threaded module has no second thread — so `#script_reload` and `Script.load` (new code at run time), a call from Dado of an `async` method (a promise Dado cannot wait for), and `#script_pause` without `--web-threads` (no thread to pause from) are refused on `#WEB`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
