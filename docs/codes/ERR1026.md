# ERR1026: an `@align` written on something with no storage to place, or given a number that is not a compile-time power of two

* class: error — an error, always
* rule: `@align(n)` states where an object's storage begins, so it goes on a declaration that has storage — a package-level variable or a member of a `type` — and `n` is a compile-time power of two the C compiler can be asked for

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
