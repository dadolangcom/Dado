# ERR0533: a method with no receiver, one more visible than its type, or one written in a declaration that holds no methods

* class: error — an error, always
* rule: a method is written in a `type` body and takes `self` or `^self` first, is no more visible than the declaration that holds it, and a `union`, `cunion`, `enum`, `foreign` or signal declaration holds none

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
