# WRN0419: a package-level declaration that writes no visibility word, so it is public by default rather than by decision

* class: warning — a warning, never an error
* rule: under `--warn-unmarked`, a package-level declaration writes `public`, `private` or `export` rather than leaving its reach to the default — a warning, and a warning under `--strict` too

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
