# ERR0532: `#signal(N)` whose `N` is not a compile-time integer, is less than 1, or asks for more storage than a signal may hold

* class: error — an error, always
* rule: a queue signal's capacity is a compile-time integer from 1 to the largest whose static storage the compiler lays out

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
