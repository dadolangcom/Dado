# ERR1206: a script's call of a Dado function whose signature cannot cross

* class: error — an error, always
* rule: a script calls a Dado function only when every parameter and the result cross — a sized integer, `f32`, `f64`, `bool`, `char8`, `char16`, `char32` or `string8`, a slice, array or tuple of those, a new string or array answered as `ref([]char8)` or `ref([]T)`, and a script class's handle by itself — so a function taking or answering an address (alone or as an element), a container of handles, a `ref` other than that answer, a map, a `distinct` type, a function, or one that is `foreign` or variadic, is refused at the script's call, naming the part that does not cross and what to give the script instead

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
