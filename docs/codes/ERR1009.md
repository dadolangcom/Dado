# ERR1009: C's `...` in a native Dado signature, or a Dado pack in a `foreign` one

* class: error — an error, always
* rule: a pack is Dado's calling convention and `...` is C's, so each is written only in a signature whose convention it is: a native signature takes `..T`, a `foreign` one ends in `...`, and neither stands in for the other

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
