# LNT0710: a map whose key and value are one type, walked with one binding — the binding is the key, and the same loop used to bind the value

* class: lint — a warning, an error under `--strict`
* rule: one binding over a map binds the key; where key and value are one type the source must say which was meant

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
