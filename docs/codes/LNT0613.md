# LNT0613: a parameter so big that passing it by value copies hundreds of bytes on every call

* class: lint — a warning, an error under `--strict`
* rule: a parameter bigger than 256 bytes is taken by pointer, because by value every call copies it — a warning while writing and an error under `--strict`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
