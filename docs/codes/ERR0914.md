# ERR0914: a `type` parameter written somewhere a type value cannot be supplied or held

* class: error — an error, always
* rule: a `type` parameter is written where a type value can be supplied and held, and is given one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
