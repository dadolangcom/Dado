# ERR0819: a key in a place position on a by-value `{K: V}` parameter — an insert may reallocate the table and free the one the caller is still holding, and the caller has no way to be told

* class: error — an error, always
* rule: a map parameter is the callee's own copy of the handle, so a caller is not inserted into through it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
