# ERR0707: a `defer` whose statement would leave the scope it is unwinding — by `return`, `break`, `continue`, `fallthrough`, `fail`, a `try` that passes a failure on, or a second `defer`, at any depth inside it

* class: error — an error, always
* rule: a `defer` runs at its scope's exit, so its statement may not leave the scope being unwound; a cleanup that can fail is `defer!`'s, which passes its failure on at the exit

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
