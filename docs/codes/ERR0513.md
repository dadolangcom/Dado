# ERR0513: a union member with no name, or with a name another member already took

* class: error — an error, always
* rule: a union member is a type and takes no name, and no two members are one type

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
