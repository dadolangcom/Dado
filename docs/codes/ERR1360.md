# ERR1360: a signal connected to a receiver, or emitted with values, whose parameter list is not the signal's

* class: error — an error, always
* rule: a signal's connection and emission match its parameter list: as many values, each crossing as a script call's would

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
