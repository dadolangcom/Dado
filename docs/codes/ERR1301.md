# ERR1301: a Dado construct written in DadoScript — memory management, a `#` spelling, an explicit width, the C boundary, or a word only Dado has

* class: error — an error, always
* rule: a DadoScript subtree — a `.dados` file, or a `class` block in any file — is written in DadoScript, so a construct only Dado has is refused there, naming what DadoScript writes instead or why DadoScript has none

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
