# ERR0719: a queue `#emit` written without `try … else`, or a `try` over a `latest` signal's `#emit`, which cannot fail

* class: error — an error, always
* rule: a queue's `#emit` fails when the queue is full and the program names what happens, with `try #emit(…) else CODE` or an `else:` suite; a `latest` signal's `#emit` cannot fail, so it is written without `try`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
