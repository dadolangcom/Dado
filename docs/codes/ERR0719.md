# ERR0719: a queue `#send` written without `try … else`, or a `try` over a `latest` channel's `#send`, which cannot fail

* class: error — an error, always
* rule: a queue's `#send` fails when the queue is full and the program names what happens, with `try #send(…) else CODE` or an `else:` suite; a `latest` channel's `#send` cannot fail, so it is written without `try`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
