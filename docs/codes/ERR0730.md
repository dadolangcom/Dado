# ERR0730: a `break` written in a `switch` arm, where C would leave the `switch` and Dado would leave the enclosing loop

* class: error — an error, always
* rule: a `case` arm ends where its body ends and `fallthrough` is how one continues, so a `break` whose innermost enclosing construct is a `switch` arm is refused rather than read as leaving the loop around it

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
