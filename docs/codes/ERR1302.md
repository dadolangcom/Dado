# ERR1302: a DadoScript construct written in Dado code — a lambda, `async`, `await`, `assert`, `super`, a script's header, or a `foreign` block over JavaScript

* class: error — an error, always
* rule: Dado code outside a `class` block is written in Dado, so a construct only DadoScript has is refused there, naming what Dado writes instead or why Dado has none; a `class` block itself is legal in a `.dado` file, and is DadoScript

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
