# ERR0304: a package name claimed by two directories, or one directory whose files declare two package names

* class: error — an error, always
* rule: a package name belongs to one directory, and a directory holds exactly one package

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
