# ERR0713: `fallthrough` in a union `switch`, whose next arm binds a member the value does not hold

* class: error — an error, always
* rule: each arm of a union `switch` binds a narrowed member, so nothing falls out of one into the next

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
