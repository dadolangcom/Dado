# ERR1003: one C type declared twice by foreign blocks

* class: error — an error, always
* rule: the emitted C reaches a foreign type by its C name, so a C type has one Dado name and one body, and the only second declaration of it is a bodiless one beside the struct or union body it forward-declares

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
