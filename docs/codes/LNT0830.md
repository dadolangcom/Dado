# LNT0830: a `ref` parameter grown here and, on some way out, neither answered nor kept: the caller's handle is stale and the block is lost

* class: lint — a warning, an error under `--strict`
* rule: a `ref` parameter is the caller's copy of the handle, and a growth moves it, so a function that grows a by-value `ref` parameter answers the grown run or keeps it — returns it, stores it, or hands it on — on every way out; a warning while writing and an error under `--strict`, because a keep the compiler cannot see is legal

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
