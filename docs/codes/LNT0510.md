# LNT0510: a code point too wide for the character type it is written against, which keeps its low bits

* class: lint — a warning, an error under `--strict`
* rule: a character literal fits the character type it is written for, or is written as the conversion that keeps its low bits — `char8('é')`; one that does not fit keeps them as that conversion would — a warning while writing and an error under `--strict`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
