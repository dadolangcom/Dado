# ERR0413: a name another package declared but does not export

* class: error — an error, always
* rule: a declaration another package does not export is not this one's to name, however plainly it is written

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
