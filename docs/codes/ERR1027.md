# ERR1027: an `@symbol` written on something that emits no function symbol, or given a word that is not a registered symbol attribute or is written twice

* class: error — an error, always
* rule: `@symbol(…)` states what the C compiler must be told about a function's emitted symbol, so it goes on a function declaration, and each word in it is one of the attributes this compiler registers, written once

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
