# ERR0535: a trait extending a type or itself, a `using` naming a type, or a child trait replacing a parent's default

* class: error — an error, always
* rule: a trait extends traits only and never itself, a `using` at a declaration's head names traits only, and a child trait may default a parent's required method but never replace a parent's default

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
