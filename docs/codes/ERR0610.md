# ERR0610: `expect` written with no message, which is a claim that does not read as one

* class: error — an error, always
* rule: `expect` takes a claim and then a message, because with no message it reads like a check that is not one

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
