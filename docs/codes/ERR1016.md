# ERR1016: a `foreign` signature's `...` written where C has no ellipsis — before the end of the parameter list, or with no fixed parameter in front of it

* class: error — an error, always
* rule: a `foreign` signature's `...` is C's own ellipsis restated, so it is written where C writes one — last in the parameter list, after at least one fixed parameter, which is the prefix a call is checked against and the anchor C reads the tail from

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
