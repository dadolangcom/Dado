# ERR0522: the address of a whole element of a shape stored as one run per slot

* class: error — an error, always
* rule: a `#soa` shape holds one run per slot, so a whole element of one is not contiguous and there is nothing for a `^` to point at

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
