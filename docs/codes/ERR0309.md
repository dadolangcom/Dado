# ERR0309: a bare name that more than one unqualified import, or one and the package or a built-in, or in a script the package and a built-in, supplies

* class: error — an error, always
* rule: a bare name means one thing: one that two unqualified imports supply, or one of them and the package's own declaration or a built-in, or in a script a Dado function of its package and a built-in, is refused where it is written rather than resolved by precedence

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
