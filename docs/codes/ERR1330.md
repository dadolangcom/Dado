# ERR1330: `await` outside an `async` method or over a value that is not `async`, an `async` call left alone on a line, an `async` slot with no value, or an `async` `init` or generic method

* class: error — an error, always
* rule: an `async` method answers `async T` and waits only on a line headed by `await`, which unwraps the `T`: so `await` is written inside an `async` method or lambda, over a value that is `async T`, heading a declaration, an assignment or a call, and never deferred; a call answering `async T` is not written alone on a line, where nothing waits for it, nor returned as the `T` it answers; a slot of an `async` type is written with its value, since a script has no null; and `init`, which runs as an instance is made, and a generic method are never `async`

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
