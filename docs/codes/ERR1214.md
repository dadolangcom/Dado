# ERR1214: a `connect` to a signal whose message carries a `ref` or a field that does not cross into a script

* class: error — an error, always
* rule: a signal's message reaches a script's handler field by field as a Dado function's answer does — an integer as an `int`, a float as a `float`, a `bool`, a character as a `string` — so a signal carrying a `ref`, which its message moves and a script cannot take or end, or any field of another type, is never connected to a script, and the program drains it in Dado

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
