# ERR0821: `#stack` storage that outlives the block that minted it — returned, stored through a `^` parameter or into a package-level variable, or assigned to a binding in an enclosing block

* class: error — an error, always
* rule: within one function, storage `#stack` put in a block is not returned, stored through a parameter or into a package-level variable, or assigned to a binding declared outside that block; storage a callee keeps is read from its summary, and one with no body — a `foreign` function, a function value — is taken to keep nothing

A diagnostic with this code names what was written and, under `help:`, the repair. Compile with `--explain` for why that site refused it.
