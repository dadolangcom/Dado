# app:input

app:input — a poll-based input subsystem.

Poll-based, not hook-based — three hooks, everything else is polled: a
backend sends into the queue, a channel, *outside* the frame barrier (during
its own input read), the runtime delivers it once a frame before `process`,
and a program drains it *inside* `process` (the safe region) with
`input.poll`.
Neutral — it imports no backend and operates on the app singleton, answering
emptily when the backend does not advertise `Input`, so the same call is safe
everywhere and a program runs headless and windowed with no branch in it.

The vocabulary below — `EventKind`, `Keycode`, `Modifier` — was written
against sokol's own numbering before there was a sokol backend, precisely so
that landing the sokol decode would be a *filler* of this shape rather than a
churn of it. It landed: `app:input/sokol` is that filler, it is a subpackage
rather than code in this file so that a program which never opens a window
does not drag sokol_app.h into its translation unit, and it needed no change
to `Keycode` or `Modifier` at all.
