# Dado icons — Workshop palette

Concept 4 ("Horseshoe d"): a solid horseshoe bowl whose arms seat into two dados in the stem.

| File | Use |
|---|---|
| dado-mark.svg / dado-mark-dark.svg | Brand mark, light / dark backgrounds (copper stem) |
| dado-mark-mono.svg | One-colour mark, `fill="currentColor"` |
| dado.svg, dados.svg, dadogl.svg (+ `-dark`) | File icons with extension label, 32px and up (label is outlined, no font needed) |
| *-small.svg (+ `-dark`) | Unlabelled file icons for 16–24px (file trees, tabs) |
| dado-wordmark.svg (+ `-dark`, `-mono`) | Wordmark B: first d jointed. Use at 48px tall and up |
| dado-wordmark-plain.svg (+ `-dark`, `-mono`) | Wordmark A: plain. Use below 48px (nav bars, headers) |
| dado-banner.svg (+ `-dark`) | 1280×320 README / social banner |
| dado-brand-guide.html | The brand guide: construction, colour, type, naming, usage. Open in a browser |
| png/ | Raster exports: mark 32–1024, wordmarks at 600/1200 wide, banners at 1x and 2x |

## Colours
- Bowl: #2B3036 (light bg), #DDE1E6 (dark bg)
- `.dado` systems, steel: #A7B2BF front / #5F6B78 side
- `.dados` scripting, copper: #E58B57 front / #AE5428 side
- `.dadogl` graphics, blue: #6E95F2 front / #2F55C9 side

## Wordmark
Letters are drawn from the mark's own parts (same bowl, stem and stroke), all as paths — no font
dependency and no third-party typeface involved. Ink: #2B3036 on light, #DDE1E6 on dark. No accent colour.
Don't set the mark beside the wordmark: the mark is a d, so the lockup reads as "d dado". Use them separately.

All text in these files (file icon labels, banner tagline) is outlined from JetBrains Mono (OFL).
