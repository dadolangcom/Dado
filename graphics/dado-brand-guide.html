Units are u: one sixty-fourth of the mark's square. Every dimension in this guide is measured on that grid.

Brand guide

A dado is a groove cut across a board so another board can sit in it. The mark is built from exactly that: a bowl seated in two dados.

01 · The joint

Two parts, two dados

A dado joint holds because the housing board runs past the joint on both sides. The mark keeps to that rule, so it is a real joint and not a picture of one.

Bowl
One solid horseshoe in ink. It is the softest part of the mark and carries no colour.
Stem
The long arm. It runs above the bowl as the ascender and 3.2u below it, so both joints are housed, never rabbets.
Dados
Two grooves, 4u deep, cut into the stem's front face. The bowl's arms seat into them.
Seam
A 0.8u gap around each arm: the only sign that the mark is two pieces.
Colour
Only in the stem: a lit front face, which the dados cut into, and a darker side.

02 · Mark

Construction

Drawn on a 64u square. Stroke and stem are near-equal (9u and 10u), so the bowl and the stem carry the same weight.

dado-mark.svg64 × 64u
Light
Dark
Mono
Clear

Keep one bowl stroke, 9u, clear on every side. Nothing enters the hatched area.

Size

The mark holds down to 16px. The seams soften below 48px, and that is fine: it still reads as a d.

Mono

On a coloured field, or where colour isn't available, use the mono mark. It takes the colour of the text around it.

03 · Wordmark

One joint, at the start

The letters are drawn from the mark's own parts: the same bowl, stem and stroke. The o is two bowls back to back. Only the first d keeps its joint.

48px and up

Jointed. The seams hold.

Under 48px

Plain. Seams this small turn to grit.

05 · Dialects & naming

One housing, three stems

Every file icon shares the bowl and the page. Only the stem changes, so a file tree reads at a glance.

Systems

Dado

*.dado

Transpiles to portable C11. The load-bearing dialect.

Scripting

DadoScript

*.dados

The high-level dialect, for scripts and glue.

Graphics

DadoGL

*.dadogl

The shading dialect. Its icons are ready for when it returns.

In prose

  • Dado, DadoScript, DadoGL, capitalised.
  • Possessive: DadoScript's.
  • Never use “dados” as the English plural of dado.

In code

  • dado, dadoc, dado-lsp, lower case.
  • Extensions: .dado, .dados, .dadogl.
  • Diagnostics carry no brand: ERR0504, WRN0419, LNT0412.

07 · Code colours

Colour by what you scan for

The editor theme is ordered by what a reader looks for first. Signatures are the loudest thing on the page, and each tier below is a quieter hue, down to ink. As with text, side tones go on light grounds and front tones on dark.

memory.dadoDado
// example/memory: reserve the result in the caller's
// ambient before opening a scratch frame.
ref []i64 squares(i64 n):
    ref []i64 out = #make([]i64, n, #return)
    using runtime.enter_temp():
        ref []i64 work = #make([]i64, n)
        for i in 0..<n:
            work[i] = i * i
        for i in 0..<n:
            out[i] = work[i]
    _ = runtime.close_temp()
    return out

Bold is never used for emphasis. It is kept for small glyphs that would otherwise vanish: operators, string escapes and character literals. In code, copper means type; in the interface, copper is still the accent. The editor themes are generated from one table, editors/vscode/themes/palette.py.
